# The Last Hour of an Epic TO THE MOON RPG - DEMO - PATCH FR
Voici un patch de traduction en français pour la démo du jeu The Last Hour of an Epic TO THE MOON RPG. Selon le créateur, cette démo offre environ 15 minutes de contenu totalement original qui ne sera pas inclus dans la version finale du jeu.

# Guide de traduction

## 1. Téléchargement
* Téléchargez le fichier `app.asar` disponible sur [cette page](https://github.com/CroustiTiges/The-Last-Hour-of-an-Epic-TO-THE-MOON-RPG-DEMO-PATCH-FR/releases/tag/first).

## 2. Dossier du jeu
* Rendez-vous dans le répertoire suivant :
  `steamapps/common/The Last Hour of an Epic To the Moon RPG DEMO/resources`

> **Note :** Vous pouvez vous y rendre facilement depuis Steam (image d'exemple ci-dessous).

<img width="1280" height="512" alt="demo_folder" src="https://github.com/user-attachments/assets/5b01b91a-c8cb-42fa-bd37-e657a81a1e2c" />

## 3. Remplacement du fichier
* Déposez votre nouveau fichier `app.asar` à la place de l'ancien.
* Lorsque Windows vous demandera si vous voulez remplacer le fichier, cliquez sur **Remplacer le fichier dans la destination**.

## 4. Démarrage du jeu
- Lancez le jeu et profitez-en en français ! 
- *Note : L'IA a grandement aidé pour cette traduction, ce que le faible volume de dialogues a permis. Aucun projet de traduction n'est prévu pour le jeu final, qui sera confié à des traducteurs professionnels et passionnés.*
